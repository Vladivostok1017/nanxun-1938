### 12.8 富金山（14:50–19:40）｜全片最完整的「三向合围」教学图

这是空间信息最丰富的一段，建议作为主参考。

- **战略方位（14:50）**：富金山在**大别山北麓**，叶家集以南、商城以东；**史河**在其东北。日军第13师团自**东**（合肥、舒城方向）西进，箭头**由东向西**；中方第71军守**正面（东侧）**。
- **战术图（15:30–15:40）**：
  - **山脊线**横贯画面，脊线上排布**白色半圆拱工事图标**（约 9–10 个），表示**沿脊线设防的连续阵地**。
  - 第36师 陈瑞河 标签在**山脊西端/南麓**（右下方有旗）。
  - 日军兵力点阵在**山脊北侧**（上方）成片堆叠。
  - **史河方向→** 标注在**右上**：日军渡河后自**东北向西南**仰攻。
- **三向合围箭头（17:50，本片最典型的一帧）**：
  - **正面强攻**：粗黑箭头自**北垂直向下**，直指山脊中段。
  - **侧背迂回**：粗黑箭头自**西北**向下摆，落在山脊**西端背后**。
  - **绕后截断退路**：最外侧的**长弧箭头**从**西北**绕过整条山脊，指向**西南（后方）**，切断退路。
  - 即：**正面牵制 + 一翼迂回 + 深远断后**，三层递进。
- **战线变形过程（关键，可作关卡节奏参考）**：
  1. 16:20 主攻换第65联队——黑点集中到山脊**中段**（第三峰方向）。
  2. 16:50 「三面围攻，第三峰失守」——黑点从**北、东北、西北**三面楔入东段脊线。
  3. 19:10 「石门口守军伤亡殆尽」——**石门口**为山脊东端的隘口，是整条防线的**铰链**。
  4. 19:20 「16时，除了主峰，阵地全丢了」——蓝点只剩**主峰一点**，被黑点环绕。
  5. 19:30 「当夜，日军才爬上山项」——主峰最后失守。
  - **战线形状演变**：`连续横线 → 东段被三面楔入 → 仅存主峰孤点 → 全失`。
- **夜袭反击（18:50）**：蓝章「打回」，蓝色点阵自**山脊南侧向上**推，白色点阵（日军）在山脊以北后撤——**仰攻夺回脊线**。
- **地形卡点清单**：山脊线（主阵地）、第三峰（东段制高点）、主峰（最后据点）、石门口（东端隘口）、傅家岗（前沿支撑点）、史河（日军渡河点）。
- **游戏含义**：**「一条脊线守到底」**的教科书式关卡——单一正面、极窄纵深、无侧翼可迂回（两侧皆陡），因此日军必须靠**兵力密度 + 火力 + 毒气**硬啃，耗时十天。这正是"血战十天"的空间原因。

### 12.9 潢川（19:50）

- **图幅**：潢川在**固始以西**，箭头**自东（固始）向西**单向推进，一条直线箭头直达潢川城。

### 12.10 广济—松阳桥—困龙山（20:10–23:40）｜公路轴线上的截断战

- **战略方位（23:40）**：广济在**田家镇东北**；日军第6师团自**黄梅（东）**西进广济；第47联队为前锋。中方第4兵团在**广济以北**，第84军在其东。**蓝色箭头自广济指向西南的田家镇**——即中方预判的日军下一步轴线。
- **战术图（21:20–22:20，困龙山—松阳桥）**：
  - 一条**公路**自**西南（广济）向东北（松阳桥）**斜贯画面，是全图的**唯一交通轴**。
  - 日军第47联队沿公路**自东北向西南**推进（黑点沿线）。
  - 中方第55军 曹福林、第86旅 陈德馨在公路**西侧（左上）**，以斜向蓝线**侧击**公路。
  - **困龙山/困龙**为路侧高地，是唯一可俯瞰公路的制高点。
  - **松阳桥**为公路上的**桥梁节点**（图右上）。
- **截断动作（22:00）**：蓝章「截断」＋蓝色箭头**横切公路**（第44师），把日军行军纵队**拦腰切断**——战线由**纵向（沿路）**瞬间转为**横向（跨路）**。
- **战线变形**：`日军沿路纵队推进 → 中方从路侧高地横切 → 日军被分段 → 中方夺回高地（蓝章「夺回」）→ 日军遗尸遍野`。
- **地形卡点**：松阳桥（桥）、困龙山（路侧高地）、吴伏七（村落）、凤凰山（广济以东，日军放毒处）、塔儿寨（广济南，第176师第1056团守）。
- **游戏含义**：**「一条公路 + 两侧高地」**的伏击/截断图原型。掌握公路即掌握机动，但公路两侧高地决定生死。

### 12.11 田家镇（23:40–29:40）｜要塞口袋与江上封锁

- **地形空间（24:00–24:20，极清晰的一帧）**：
  - **长江**自西北向东南流，在田家镇处**急弯收窄**（字幕：「江面收窄到不足五百米」）。
  - 田家镇在**长江北岸（图中偏左）**；**半壁山**在其**西南对岸**（南岸）；**富池口**在南岸下游。
  - 要塞背后为**湖沼群**：**马口湖（西北）、黄泥湖（正北）、武山湖（东北）**——三湖环绕，形成**背水口袋**。
  - 外围山地自北向南排列：**铁石墩（最北）—松山口—骆驼山—无名高地—玉屏山—阳城山（西北）**，构成一道**向北的弧形屏障**。
  - **空间判断**：田家镇是一个**三面环湖、一面临江、北面靠山**的**口袋地形**——守军无法从背后获得补给，日军只要封住北面山口与江面即可合围。
- **封锁示意**：江面上方画**锯齿状拦江线**（横跨江面），并有舰船图标——表示日军**江上封锁**。字幕「二十多艘日舰掩护陆战队」。
- **日军进攻几何**：
  - **北面**：今村支队自**松山口—骆驼山**方向**由北向南**压（第一批箭头）。
  - **东面/江面**：波田支队 + 第11战队 + 特别陆战队自**武穴（东南）沿江上溯**，箭头指向**田家镇侧后**。
  - **南面**：海军陆战队在**盘塘**（南岸）**强行登陆**，从背后夹击。
  - 即：**三面合围，仅西面（阳新方向）留缺口**。
- **战线变形过程**：
  1. 24:10 中方第9师、第57师沿**北面弧形屏障**布防（蓝锯齿线）。
  2. 25:20 「阵地四次易手」——蓝线与黑点在胡家山、鸭掌庙一带**反复推移**。
  3. 26:40 鸭掌庙「失守」（红章）——黑点**楔入弧线中段**。
  4. 27:40–28:10 沙子垴、乌龟山一线被压缩到**要塞核心**；「两个营被团团围住」——出现**局部包围圈**（黑点环绕蓝点）。
  5. 28:50 「守滩的第5连几乎全部倒下」——**江岸滩头阵地**亦被突破。
  6. 29:00 「田家镇陷落」。
  - 战线形状演变：`北面弧形屏障 → 中段楔入 → 被压缩至要塞核心 → 三面合围完成`。
- **突围示意（24:40）**：第337团一部在**田家镇城区**巷战，一条**虚线箭头自城区向西南（富池口方向）**——即入夜突围方向。
- **地形卡点**：松山口（北面隘口）、玉屏山（要塞东侧制高点）、半壁山（对岸，控制江面）、盘塘（南岸登陆点）、富池口（南岸要点）。
- **游戏含义**：**「背水口袋 + 三面合围」**的防御图原型。守方的最优解是**及早放弃口袋、退守西面出口**；片中「伤亡1.17万，失踪1400」正对应被合围的代价。

### 12.12 小界岭—沙窝（30:00–34:30）｜山口防线与合围威胁

- **战略方位（30:00）**：**商城**在北（图顶）；**沙窝、经扶**在西；**小界岭**在中；**打船店**在东；**叶家集**在东北；**大别山**在南。
  - 日军第16师团 藤江惠辅在**商城**，箭头**向南**（经余家集指向沙窝）。
  - 日军第13师团 荻洲立兵在**东侧**，箭头**向西南**（指向打船店）。
  - 中方第71军 宋希濂在**西段**，第30军 田镇南在**中段**，第3兵团 孙连仲在**后方（南）**。
- **战线形状（30:10）**：一条**西北—东南走向的蓝色锯齿线**，横亘于沙窝与郭店/老庙/小界岭之间，**依托山口设防**。要点分布：`沙窝（西北端）— 郭店 — 老庙/小界岭（中）— 打船店（东南端）`。
  - 这条线的特点是**沿等高线走**，且**背靠大别山主脉**，纵深极浅。
- **战线变形**：
  1. 30:20 「沙窝失守，守军退上南面山口」——**西端被突破**，战线**向南折叠**（不是整线后退，而是西段绕轴旋转）。
  2. 30:30 打船店「被打退」（蓝章「打退」）——**东端守住**。
  3. 31:50–32:10 新店、鸦雀尖（**东南端**）成为新的焦点，第27师 黄樵松在此死守。
  4. 34:30 「10月21日，孙连仲奉命转进」——多条**蓝色虚线箭头自西北向东南、向南扇形散开**，为**有序撤退**示意。
- **转进示意（32:20）**：虚线箭头自沙窝/老庙/小界岭**向南、向西南**分多路指向经扶与武汉方向——**多路平行撤退**，非单路溃退。
- **地形卡点**：沙窝（西北山口）、小界岭（中央山口）、打船店（东南隘口）、新店—鸦雀尖（东南支撑点）、黄土岭/黄皮尖（东段高地）、西马冲（放毒处）、李家山、郭店、老庙。
- **游戏含义**：**「一条依托山脊的横向防线，两端为铰链」**模型。全片反复出现「两端失守→战线旋转」的几何：沙窝失守不是全线崩溃，而是**西端被压下**，防线转为南北向。

### 12.13 万家岭（35:00–43:30）｜全片唯一的完整合围歼灭图

这是空间信息最密集、也最适合做「包围战」关卡的段落。

- **进入包围圈的过程（35:00–35:10）**：
  - 第106师团自**马回岭（东北）**出发，一条**黑色粗箭头向西南**深入山区，字幕「离开马回岭，钻进山区」。
  - 即：日军**主动脱离交通线**，进入**无道路的山地**——这是被围的空间前提。
- **包围圈几何（36:20 起，逐帧清晰化）**：
  - **万家岭**为盆地中心偏东；**张古山**在西南；**大金山**在东南；**雷鸣鼓刘、田步苏、哔叽街**在西/南。
  - 蓝色**锯齿弧线**逐步合拢：
    - 36:20（10/2）：仅**南面**一段弧（张古山方向）。
    - 37:50（10/6）：形成**大半环**，缺口在**东北**（德安方向）。
    - 39:20（10/9）：**完整 C 形**，缺口收窄至东侧。
    - 42:20（10/15）：C 形闭合度最高，仅**东面甘木关—柘林**方向留口（日军援军来向）。
  - **关键空间特征**：包围圈**始终在东面留缺口**——因为日军援军（铃木支队、佐枝支队）正从**东/东南**推进。这是全片最重要的空间张力：**围歼与解围在同一轴线上对冲**。
- **向心总攻（37:50，最典型的一帧）**：
  - **蓝色箭头从四个方向同时指向圆心**：第66军自**北**、第91/第142/第187师自**西与西南**、第4军自**东**、第74军自**东南**。
  - 圆心为第106师团黑牌。这是一个标准的**同心多轴收缩**示意。
- **局部战术几何**：
  - **张古山（38:10–39:50）**：山脊线东西向，日军黑点在**山脊北侧**（上方）成密集阵列，中方第51师在**南麓**仰攻。多条虚线箭头自**南向北**逐波冲击。夜间（39:30）以「手电+机枪」近战，战线压缩至**数十米**。
  - **杨家坂（37:00–37:20）**：高地东端为争夺焦点（标「杨家坂东端高地」），中方在**东侧**（右），日军在**西侧**（左），战线为**南北向的窄正面**。
  - **狮子崖（37:20）**：与**扁担山**相对，日军自**扁担山（西北）**扑向狮子崖（东南），为**短距离对冲**。
  - **老虎尖—石堡山（40:10）**：第66军沿**东西向山脊**布防，日军自**北**来；「三百多人被包围歼灭」处出现**小黑点被蓝点环绕**的局部包围圈。
  - **松树熊（41:00）**：画有**环形合围圈**（白色虚线圆环），日军残部在环内，中方自**东南**压入——**最小尺度的包围示意**。
  - **跑马岭（40:20）**：**战车图标**自**西向东**沿道路推进，蓝章「突破」——日军以装甲沿谷地突破阻援线。
- **解围轴线（42:20–42:30）**：
  - **铃木支队**自**南（柘林方向）向北**推进至甘木关；**佐枝支队**自**西（箬溪）向东**推进。
  - 中方阻援部队（第91师、第142师、第18军两个师）呈**南北向细长防线**，横在解围轴线上。
  - 42:00「第91师全师只剩400余人」——阻援线的空间位置是**甘木关**，即包围圈东侧的唯一缺口。
- **地形卡点**：万家岭（盆地中心）、张古山（西南锁钥）、大金山（东南制高点）、雷鸣鼓刘/田步苏/哔叽街（西侧村落群）、甘木关（东侧缺口）、柘林（援军来向）、箬溪（佐枝支队来向）、白水街（西北）。
- **游戏含义**：**「围三缺一」**的经典包围战地图——包围圈刻意留口，缺口外另设**阻援线**。玩家面对的是**双重任务**：内圈收缩 + 外圈打援，两条战线共享兵力。

### 12.14 阳新—武汉（43:30–45:30）｜合围与终局

- **阳新（43:50–44:00）**：阳新在**武汉东南**；日军第6师团自**北（蕲春、广济）**南下，第9师团自**东（九江）**西进，两箭头**在阳新附近合流**后指向武汉。中方第2兵团/第4兵团在**西侧**（武汉方向）。
- **武汉攻城（45:20）**：
  - **汉口**在长江与汉水交汇的**西北**；**汉阳**在**西南**；**武昌**在**东南**（江对岸）。
  - **戴家山**在汉口**正北**，为进攻发起高地。
  - 箭头：一条**粗黑箭头自戴家山垂直向南**直指汉口；另一条自**东**指向武昌。**第6师团**在黄陂（北），**波田支队**在东南，**第94军**（郭忏）在西南（汉阳方向）。
  - **战线形状**：**两路对进、隔江分击**（汉口/汉阳一路，武昌一路）。
- **中山舰（44:20–44:50）**：**长江江面纵向贯穿画面**，中山舰居中，**9 架日机环绕**（左4、上3、右2），后舰体倾倒冒烟——**空袭单舰**的空间示意。
- **毒气使用范围（45:40）**：地图以**黄绿色晕染区**标出两片：**北片（富金山一带）**、**南片（九江—马当—朱家山一带）**——表示毒气使用集中于**两个山岳攻坚正面**，而非全战线。
- **终局态势（46:10）**：日军推进至**岳阳、通城**一线后停止；箭头终点即**战线定格线**。

### 13.2 战术要点类型（关卡级原型）

| 原型 | 几何特征 | 片中实例 | 设计要点 |
|---|---|---|---|
| **山脊线防御** | 单条脊线横贯，两侧陡坡不可展开 | 富金山、小界岭、老虎尖 | 正面极窄、纵深极浅；只能硬啃 |
| **沿江狭长山脊** | 山脊两侧皆水，仅沿脊线机动 | 长山 | 一线天隘路，少兵可久守 |
| **背水口袋** | 三面湖沼/江，一面靠山 | 田家镇 | 守方无退路；合围成本低 |
| **孤立高地** | 等高线闭合，仅南北两坡可接近 | 老虎山、朱家山、张古山 | 单轴拉锯，反复易手 |
| **村落要点** | 道路横穿，房屋密集 | 孔家祠、河洲上、新店 | 被楔入→反冲击的短周期震荡 |
| **公路截断** | 一条公路 + 两侧高地 | 松阳桥、广济公路 | 纵队被横切即分段 |
| **城垣单点突破** | 闭合城墙 + 城门 | 瑞昌（东门） | 一旦破门即全城失守 |
| **湖岸滩头** | 水面→岸线，点状抗击 | 姑塘、盘塘、藏山矶 | 攻方有水面机动，守方被动 |
| **围三缺一** | C形合围 + 缺口外阻援线 | 万家岭 | 内外双线共享兵力 |
| **多路平行撤退** | 扇形虚线 | 小界岭转进（10/21） | 有序退却而非溃退 |

### 13.3 战线变形的五种基本模式（本片全覆盖）

1. **正面平推**：潢川（单向直线箭头）、田家镇北面。
2. **钳形/双翼合击**：孔家祠（西北+东北双弧）、富金山（正面+侧背）。
3. **单翼深远迂回**：陈家山（700余人绕到背后）、富金山「绕后截断退路」。
4. **横向截断**：松阳桥（横切公路纵队）。
5. **向心合围**：万家岭（四方向心箭头、C形圈逐步闭合）。

### 13.4 战斗强度的可视化语法（可反推兵力密度）

片中用**散点密度 + 爆炸光斑 + 火力线**表示强度，规律如下：

| 视觉表现 | 含义 | 兵力密度感 |
|---|---|---|
| 稀疏单排点阵 | 一个连/排据守 | 低 |
| 成片堆叠黑点（数十点） | 一个大队/联队密集冲锋 | 中—高 |
| 多排层叠点阵 + 持续爆炸光斑 | 师团级正面强攻 | 高 |
| 蓝色点阵被黑点**环状包围** | 局部被围 | 极危 |
| 白色/黄色密集弹道线（放射状） | 交叉火力/被火力覆盖 | 高（守方火力） |
| 橙红光斑 + 黑烟团同时出现 | 炮击/轰炸 + 燃烧 | 极高 |
| 飞机剪影数量 | 单次出动架数（3/9/15/18/21/24） | 空中强度分级 |

> 注意：点阵密度是**示意性**的，不是精确兵力换算。但**相对密度**（黑点 vs 蓝点）与画面标注的兵力数字（如「约1200 vs 700余」「约3500 vs 2000余」）**大体一致**，可作为密度—兵力的校准参考。

### 13.6 空间信息缺口（补充第九节）

25. **等高线数值缺失**：全片等高线仅作视觉纹理，**无海拔标尺、无坡度数值**，无法换算实际地形起伏。
26. **比例尺缺失**：除零散的「武汉XXX公里」距离标注外，**所有战术图均无比例尺**，无法确定战线实际长度与部队展开宽度。
27. **道路等级未区分**：公路、土路、小径在图上**同一线型**，仅广济公路因被截断而突出，无法判断通行能力。
28. **水系通航性未标**：长江、汉水、湖泊仅作面状水体，**未区分可通航/不可通航**，湖沼的通行难度完全未知。
29. **阵地工事强度未分级**：白色半圆拱图标统一表示工事，**未区分野战壕、碉堡、要塞炮台**（仅文字标签提示「要塞」「炮台」）。
30. **方位与真北**：地图基本北向上，但**无指北针**，且部分战斗示意图（如田家镇、万家岭）为局部旋转视图，**相对方位需以地名反推**。
